# GHOST // SHELL (شبیه‌ساز هکر)
**ساخته‌شده توسط امیر محمد (Amir Mohammad)**

یه PWA یک‌صفحه‌ای، کاملاً نمایشی و سرگرمی — هیچ شبکه یا سیستم واقعی رو اسکن یا نفوذ نمی‌کنه، فقط ظاهرش شبیه فیلم‌های هکری‌ـه. مناسب برای پرت کردن حواس دوستان یا پس‌زمینه‌ی استریم 😄

## قابلیت‌ها
- بوت‌سکوئنس ترمینالی موقع باز شدن
- بارش ماتریکس در پس‌زمینه + اسکن‌لاین + گلیچ روی تیتر
- HUD بالای صفحه با IP/ping/CPU/encryption جعلی که دائم عوض می‌شه
- تایپ کردن هرجای صفحه → سیل کد جعلی روی ترمینال می‌ریزه (مثل hackertyper)
- دکمه‌های `INITIATE BREACH`، `SCAN NETWORK`، `DECRYPT FILE`، `WIPE LOGS` → یه سکانس پراگرس‌بار و لاگ اجرا می‌کنن و در آخر یه دیالوگ «ACCESS GRANTED» با افکت فلش قرمز نشون می‌دن
- دکمه‌ی FULLSCREEN برای نمایش تمام‌صفحه

## نصب روی گوشی
1. در GitHub یک مخزن جدید و Public بسازید.
2. هر ۵ فایل (index.html، manifest.json، sw.js، icon-192.png، icon-512.png) را در ریشه‌ی مخزن آپلود و Commit کنید.
3. Settings → Pages → Source: Deploy from a branch → Branch: main، پوشه‌ی / (root) → Save.
4. بعد از ۱-۲ دقیقه آدرس `https://USERNAME.github.io/REPO/` فعال می‌شود؛ در Chrome گوشی باز کنید → ⋮ → Install app.

## راه سریع (فقط تست)
فایل index.html را مستقیم با Chrome باز کنید؛ همه‌چیز سمت کلاینت و آفلاین کار می‌کند، نیازی به اینترنت یا کلید API نیست.
